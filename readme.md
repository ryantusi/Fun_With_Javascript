# 🎯 Fun With JavaScript

A collection of small yet fun **JavaScript projects** exploring different concepts like APIs, HTTP requests, DOM manipulation, and interactive games.  
This repository serves as a playground for practicing and experimenting with core JavaScript skills. 🚀

---

## 📁 Projects Included

### 🎬 Film Finder
- A movie search app that uses the **IMDb API**.
- Fetches and displays movie details dynamically.

### ✍️ Form A Story
- Interactive story generator.
- Handles **HTTP requests** to fetch and render story content.

### 🔢 Number Guesser
- Classic number guessing game.
- Built with **JavaScript logic & DOM manipulation**.

### 🎹 Piano Player
- A digital piano using **DOM events** and sound files.
- Keys trigger actual piano sounds for an interactive experience.

---

## 🛠️ Tech Stack
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **APIs & HTTP Requests**
- **DOM Manipulation**
